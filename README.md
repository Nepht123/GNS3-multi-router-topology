# GNS3 Multi-Router Network Topology

A GNS3 simulation project designed to model a stable, scalable multi-node network architecture. This repository demonstrates practical implementations of dynamic routing protocols, IP addressing schemes, and localized traffic optimization.

## Network Features
* **Dynamic Routing:** Configured with Open Shortest Path First (OSPF) protocols to handle automated path routing and traffic failover.
* **Traffic Isolation:** Implements Virtual Local Area Network (VLAN) segmentation to manage domain security and optimize bandwidth flow.
* **Network Stability:** Simulates optimized virtual routing environments to successfully troubleshoot and lower data latency.

## Tech & Tools Used
* **GNS3** (Graphical Network Simulator-3)
* **Cisco IOS Images / Virtual Routers & Switches**
* **VirtualBox / Linux** (for testing node endpoints)

## How to Run the Project

1. **Extract the Project Configuration:**
   Download and extract the `GNS3 multi router topology.zip` file into your local GNS3 projects directory.

2. **Load in GNS3:**
   Open the GNS3 client and select **File > Open Project**, then navigate to the extracted `.gns3` project file.

3. **Start the Nodes:**
   Click the green **Start** button in GNS3 to boot up all virtual switches, routers, and test nodes simultaneously.
